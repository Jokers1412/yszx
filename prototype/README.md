# 云枢智学 · 页面原型（Prototype）

基于《云枢智学-需求文档》生成的**可交互页面原型**，纯 HTML / CSS / JavaScript 实现，无服务端逻辑、无外部依赖，浏览器直接打开即可体验。

## 快速开始

双击打开 `index.html`（原型入口导航页），从入口页进入**学员端**或**管理端**。所有页面均可通过导航/按钮互相跳转。

> 建议使用 Chrome / Edge 浏览器打开。
> 原型首次打开会自动以演示账号登录（学员端「林小雨」、管理端「admin」），退出登录后可体验游客/登录流程。

## 原型演示说明（与真实实现的差异）

| 方面 | 原型行为 |
|---|---|
| 登录 | 任意非空账号密码均可登录（登录页有提示）；连续 5 次密码 `000000` 提交演示锁定提示 |
| 数据 | 全部来自 `assets/js/data.js`，增删改在当前页面会话内生效，刷新恢复 |
| 持久化 | 练习进度、面试会话、新手引导、登录态使用 localStorage（对应文档的本地持久化要求） |
| AI 能力 | 简答批改、面试问答评分使用脚本化模拟数据（含「评分中→思考中」过程动画） |
| 语音 | 面试语音播报优先调用浏览器 speechSynthesis；语音输入为模拟识别 |
| 导入/导出 | 导入为模拟解析预览向导；日志导出为真实 CSV 下载，其余导出为提示 |
| 外链 | 「去B站学习」打开 B 站首页占位；页脚支持/关于两组链接为占位（按文档本期不开发） |

## 覆盖的功能点

按需求文档功能结构总览逐项对应：

- **学员端**（`portal/`）：首页、注册、登录、找回密码、题库中心、刷题练习、错题本、学习路线、面试配置、模拟面试、面试报告、面试记录、个人中心
- **管理端**（`admin/`）：后台登录、数据看板、学科管理、B站课程库、题库管理、面试题库管理、学习路线管理、学员管理、用户管理、角色管理、操作日志、系统设置

关键交互约定（Toast 三级反馈、破坏性操作二次确认、筛选变更页码重置、批量操作条、空态文案等）按文档 §6「通用交互约定」实现。
