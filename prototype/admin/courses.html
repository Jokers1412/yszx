导入说明
1. 表头按列名识别，列顺序可变；必需列「课程名称」「时长（分钟）」缺一即整份文件报错。
2. 可选列：所属学科、来源、BV号、封面、播放链接；单次 ≤ 2000 行、文件 ≤ 5MB。
3. 「所属学科」一格内可写多个学科（中英文逗号分隔），第一个为主学科，其余为关联学科；不属于任何已有学科的课程归入「其他学科」。
4. Excel 为权威数据源：BV号与库中已有课程重复时覆盖更新该课程；无 BV号时按「课程名称 + 来源」匹配；为空的可选列按空值写入（所属学科为空 → 归入「其他学科」），不保留库中原值；关联学科整体替换。
5. 列中学科名无法识别的行视为警告行，归入「其他学科」导入。
6. 任一无效行（课程名称缺失、时长非数字等）即整份拒绝导入，报出行号与原因，一行数据都不写入，修正后重新上传。
