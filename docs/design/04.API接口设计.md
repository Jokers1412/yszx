## 1. 总则

### 1.1 路径、版本与命名

| 项 | 约定 |
|---|---|
| 学员端前缀 | `/api/portal/v1/*`（02 D2） |
| 管理端前缀 | `/api/admin/v1/*`（02 D2） |
| 风格 | REST：资源用名词，`GET` 读取、`POST` 创建/动作、`PUT` 整体更新、`PATCH` 局部更新、`DELETE` 删除（api-rules §2） |
| 动作型接口 | 状态流转/批量等动作用子资源或动作后缀（如 `POST /questions/{id}/review`、`POST /questions/batch-delete`），不混入查询参数 |
| 敏感信息 | 密码、令牌、验证码**不放 URL 查询参数**（api-rules §2.5）；文件走 multipart 或响应流 |
| 字段命名 | JSON 字段 **lowerCamelCase**（✅ Q1）；与 03 表字段为 snake_case ↔ lowerCamelCase 一一映射（如 `last_wrong_at` → `lastWrongAt`） |
| 时间格式 | 请求/响应时间统一 **Asia/Shanghai 本地字符串** `YYYY-MM-DD HH:mm:ss`（毫秒场景 `YYYY-MM-DD HH:mm:ss.SSS`）；入库 UTC（03 §1.1） |
| 枚举值 | JSON 中用**小写驼峰字符串**枚举（如 `difficulty: "easy"`），与 03 数值映射见附录 C |
| 响应边界 | 不返回 `passwordHash`、`deletedAt` 等内部字段（api-rules §4.3）；派生字段（统计值、进度、`isAdmin` 等）为计算值，**不新增数据库字段** |

### 1.2 统一响应结构（✅ Q1 定稿）

**成功**（HTTP 200；创建资源成功可用 201）：

```json
{ "code": 0, "message": "success", "data": { } }
```

**失败**（HTTP 状态码表达语义 + 稳定字符串业务码）：

```json
{
  "code": "PARAM_VALIDATION_FAILED",
  "message": "参数校验失败",
  "data": { "fieldErrors": [ { "field": "phone", "reason": "手机号格式不正确" } ] }
}
```

| HTTP 状态码 | 语义 | 典型业务码 |
|---|---|---|
| 400 | 参数错误/校验失败/导入整份拒绝 | `PARAM_VALIDATION_FAILED`、`PARAM_FILE_INVALID`、`BIZ_IMPORT_REJECTED` |
| 401 | 未认证/令牌无效或过期/refresh 失效 | `AUTH_TOKEN_INVALID`、`AUTH_TOKEN_EXPIRED`、`AUTH_REFRESH_INVALID` |
| 403 | 已认证无权限 | `PERM_DENIED` |
| 404 | 资源不存在（含已逻辑删除） | `RESOURCE_NOT_FOUND` |
| 409 | 业务状态/唯一性冲突 | `BIZ_STATE_INVALID`、`BIZ_PHONE_REGISTERED`、`BIZ_BVID_EXISTS`… |
| 423 | 账号锁定 | `AUTH_LOCKED` |
| 429 | 频控/配额 | `RATE_LIMITED`、`BIZ_INTERVIEW_QUOTA_EXCEEDED` |
| 500 | 服务端内部错误（不泄露细节） | `SYS_INTERNAL` |
| 503 | AI 等外部依赖暂不可用（可重试） | `SYS_AI_UNAVAILABLE` |

> 业务码清单初版见附录 B（稳定不复用；调整须回改本文）。

### 1.3 分页、排序与筛选（✅ Q1 定稿）

- 列表接口统一入参：`pageNum`（int，默认 **1**，从 1 起）、`pageSize`（int，默认 **10**，上限 **100**）；筛选/排序参数随接口定义。
- 列表统一出参（`data` 内）：`{ "list": [], "total": 0, "pageNum": 1, "pageSize": 10 }`。
- 筛选变更后页码重置为 1 由**前端**控制（需求 §6）；接口不记忆筛选状态。
- 排序：各列表排序规则在接口内固定或以 `sort` 参数声明（枚举值随接口定义），不开放任意字段排序。

### 1.4 参数校验与异常处理

1. **服务端必须校验全部输入**（api-rules §3）：Pydantic 声明类型、必填、长度、范围、枚举、格式（手机号 11 位、验证码 6 位、密码 6-20 位等，见各接口）。
2. 校验失败 → 400 `PARAM_VALIDATION_FAILED`，`data.fieldErrors` 尽可能指出字段与原因（api-rules §5.4）。
3. 枚举/数值越界、数组越界（如选项 2~6 个）随各接口规则校验。
4. 未捕获异常 → 500 `SYS_INTERNAL`，message 通用文案，**不泄露内部实现**（api-rules §5.3）。
5. 逻辑删除行按不存在处理 → 404（03 §3.2）。
6. 文件上传：校验扩展名、大小（Excel ≤5MB；图片 jpg/png ≤2MB），非法 → 400 `PARAM_FILE_INVALID`。

### 1.5 认证与登录态（✅ Q2 双 token）

| 项 | 约定 |
|---|---|
| Token 形态 | JWT，HTTP 头 `Authorization: Bearer <accessToken>` |
| 双端隔离 | 学员端与管理端**两套独立 JWT**（不同密钥/受众，02 D3）；学员 token 访问 `/api/admin/*`（反之亦然）→ 401 |
| access token | 有效期 **2 小时** |
| refresh token | 有效期：勾选「记住我」**30 天**，否则 **7 天**；`POST /auth/refresh` 用 refresh 换发新 access（滚动续期） |
| 失效 | 登出、修改密码、重置密码 → 该端全部 refresh 失效（Redis 记录，02 D12）；access 靠短期过期自然失效 |
| 公开接口（无 token） | 学员端：`/auth/*`、`/home/stats`、`/home/hot-stages`、`/settings/public`；管理端：`/auth/login`。其余均需登录 |
| 游客边界 | 严格按需求 1.2 角色表（游客仅浏览首页/注册/登录/找回密码）——题库中心、路线等**均需登录** ⚠️ 口径 S9 |
| 后台账号登录学员端 | ✅ Q4：`/portal/v1/auth/login/*` 兼容 `admin_user` 凭证，登录成功响应带 `isAdmin: true` 与后台账号基础信息（无学习数据），仅用于显示「管理后台」下拉入口；进入管理端仍需单独登录 |

### 1.6 权限校验（RBAC）

| 项 | 约定 |
|---|---|
| 模型 | 管理端 RBAC，9 组 33 项权限码（附录 A，02 D4）；服务端接口级强制校验，前端按 `permissionCodes` 渲染菜单/按钮 |
| 超级管理员 | `super_admin` 角色**免检全部权限**；角色管理接口**仅超管可用**（✅ Q3） |
| 按钮归并口径 | ✅ Q3：权限树无一一对应点的按钮按「最接近点」归并——同组破坏性操作（删除/重置密码/启禁用/批量）归「编辑」或「禁用」，导出/模板归「查看」或「新增」（模板随新增）；**全量映射见各接口「权限」列，供审** |
| 学员端 | 仅区分 游客/登录/身份（含 `isAdmin` 标记），无权限点 |
| 无权限行为 | 403 `PERM_DENIED`；无权限的菜单/按钮前端不展示（需求 §6） |

### 1.7 频控与安全（T6 ✅ 已定稿阈值，服务端 Redis 实现）

| 场景 | 阈值 | 覆盖接口 |
|---|---|---|
| 登录失败锁定 | 同账号连续 5 次密码错误锁 5 分钟 | `POST /auth/login/password`、`/admin/v1/auth/login`；锁定返回 423 `AUTH_LOCKED`（提示剩余分钟，不暴露阈值） |
| 验证码获取 | 同手机号 60s 1 次、日 10 次 | `POST /portal/v1/auth/sms-code` |
| 验证码校验失败 | 同验证码连续 5 次失效 | 注册/登录/找回密码各验证码接口 |
| 接口限流 | IP + 账号双维度 | 登录、注册、找回密码、验证码、`POST /interviews`；超限 429 `RATE_LIMITED` |

### 1.8 导入导出约定

| 项 | 约定 |
|---|---|
| 导入 | 两段式：`POST /xxx/import/preview`（multipart 上传 → 解析校验 + 摘要 + 行级错误，生成 `importToken` 存 Redis 短时）→ `POST /xxx/import`（携 `importToken` 确认执行）；**任一无效行整份拒绝**（报行号与原因，一行不写），确认接口同样整份原子执行（03/需求 4.3.2 校验口径） |
| 导入模板 | `GET /xxx/import/template` 下载 .xlsx 模板（含示例行） |
| 导出 | `GET /xxx/export` 按当前筛选条件**同步流式下载**（`Content-Disposition: attachment`），不建任务表（B5 ✅）；题目导出 14 列与导入表头一致、单次 ≤1 万行；日志导出 CSV（UTF-8 BOM） |
| 权限 | 课程导入仅校验「新增」权限（需求 4.3.2 ✅）；题库导入 → `question:import`；导出 → 各接口权限列 |
| 文件存储 | 上传文件（头像/Logo）统一存 **MinIO 对象存储**（S3 兼容，02 D15），上传接口返回对象访问 URL；数据库仅存 URL，不存文件本体 |
